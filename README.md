# Japanese Version of the Justice Sensitivity Inventory (JSI-J)

ターン他（2019）において公正感受性尺度日本語版を開発した際に実際に使用した導入文、質問文、回答選択肢を示す資料を公開するためのリポジトリです。

This repository provides the instructions and response options used in the development and validation of the Japanese version of the Justice Sensitivity Inventory (JSI-J; Tham et al., 2019).

## Reference

ターン 有加里ジェシカ・橋本 剛明・シュミット，マンフレッド・唐沢 かおり（2019）．公正感受性尺度日本語版（JSI-J）の作成　心理学研究，90, 503‒512. https://doi.org/10.4992/jjpsy.90.18234

Tham, Y. J., Hashimoto, T., Schmitt, M., & Karasawa, K. (2019). Development of a Japanese version of the Justice Sensitivity Inventory (JSI-J). *Japanese Psychological Research, 90*(5), 503–512. https://doi.org/10.4992/jjpsy.90.18234
